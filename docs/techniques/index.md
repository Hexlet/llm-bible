# Каталог приёмов

Конкретные способы постановки задач, работы с материалами, проверки и повторного использования. Для каждого приёма — какую задачу решает, когда применять, пример формулировки, как проверить результат и типичные ошибки.

## Постановка задачи

- Контекст и аудитория результата.
- Критерии готовности и формат ответа.
- Примеры и образцы.
- Разбиение большой задачи на шаги.
- Модель сначала задаёт вопросы.

## Работа с материалами

- Работа только по приложенным источникам.
- Цитаты и ссылки на место в документе.
- Отметь пропуски и противоречия: ответ «в источнике сведений нет» вместо догадки.
- Длинные документы и подборки файлов.
- Извлечение данных в таблицу.

## Проверка и улучшение

- Самопроверка по списку критериев.
- Несколько вариантов и выбор лучшего.
- Вторая модель как рецензент.
- Пошаговая сверка утверждения с первоисточником.
- Поиск слабых мест в собственном решении.

## Повторное использование

- Шаблон промпта с переменными.
- Шаблон скила: инструкция, примеры и критерии проверки.
- Сжатие длинного разговора и перенос в новый.

Материалы каталога готовятся. Состав может измениться, рабочий план — в PLAN.md репозитория.

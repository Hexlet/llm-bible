# Создание материалов

Тексты, документы, презентации и изображения; отдельный маршрут для видео, голоса и музыки; авторство и восприятие ИИ-материалов.

## Планируемые материалы

- Тексты.
- Презентации, документы и таблицы.
- Изображения.
- Отдельный маршрут: видео, голос и музыка.
- Авторство и восприятие.

Материалы раздела готовятся. Состав может измениться, рабочий план — в PLAN.md репозитория.

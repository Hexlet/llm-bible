# Справочник инструментов

Чат-ассистенты, сервисы для исследований, генерация медиа, автоматизация, агенты, вайбкодинг и локальные модели. Для каждого инструмента — задачи, возможности, тарифы с датой проверки, условия обработки данных и доступ из России.

## Планируемые материалы

- Чат-ассистенты: ChatGPT, Claude, Gemini, Microsoft Copilot, Grok, DeepSeek, Qwen, Mistral Le Chat.
- Российские ассистенты: GigaChat, Алиса и модели YandexGPT.
- Поиск и исследования: Perplexity, NotebookLM, режимы глубокого исследования.
- Изображения, видео и голос.
- Автоматизация: n8n, Make, Zapier.
- Агенты и вайбкодинг: Claude Code, Codex, Cursor, Lovable, Bolt, Replit.
- Локальные модели: Ollama, LM Studio и открытые семейства моделей.

Это рабочий список. Сервисы, тарифы и функции меняются, поэтому перед написанием раздела состав сверяется с первоисточниками.
